# Brainridge Bank — Angular application

This directory contains the Angular application.

See the [project README](../README.md) in the repository root for an overview, setup instructions, architecture notes, and design decisions.

## Quick reference

```bash
npm install    # install dependencies
npm start      # dev server at http://localhost:4200
npm test       # unit tests (Vitest)
npm run build  # production build to dist/angular
```
